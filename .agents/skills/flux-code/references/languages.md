# Languages index

Lookup table only. Open the one language file that's actually in play — skip the rest.

| Language | One-liner | Detail |
|---|---|---|
| Python | Batteries-included stdlib, dynamic typing with optional type hints, readability-first. | [languages/python.md](languages/python.md) |
| JavaScript / TypeScript | Single-threaded event loop, prototype-based objects; TypeScript adds a structural type system on top. | [languages/javascript-typescript.md](languages/javascript-typescript.md) |
| Java | Static typing, JVM, verbose-but-explicit OOP, heavy enterprise ecosystem. | [languages/java.md](languages/java.md) |
| Go | Static typing, explicit error handling, goroutines/channels for concurrency, deliberately small language. | [languages/go.md](languages/go.md) |
| C# / .NET | Static typing, CLR, close cousin to Java with more language-level sugar (LINQ, async/await origin). | [languages/csharp.md](languages/csharp.md) |
| Rust | Static typing, no garbage collector, ownership/borrow-checker enforces memory and concurrency safety at compile time. | [languages/rust.md](languages/rust.md) |

Not every language a codebase uses needs a file read here — this index exists so the agent looks up one entry instead of holding all of them in context.
