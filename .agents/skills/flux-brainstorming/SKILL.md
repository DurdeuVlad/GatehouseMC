# Flux Brainstorming

## Input

Problem, goals, constraints, evidence, and any rejected assumptions.

## Actions

- Reframe the problem from multiple perspectives.
- Generate materially different directions.
- State likely benefit, risks, tradeoffs, and failure modes.
- Identify what is easy, hard, and impossible to test.
- Leave selection to the user or a later decision step.

## Contract contribution

- Goal: produce viable alternative directions and make tradeoffs visible.
- System: generate and compare options before prematurely converging.
- Constraints: keep evidence, hypotheses, and preferences separate.
- Evaluation: test whether alternatives address the stated problem and constraints.

## Output

Return competing framings, solution directions, tradeoffs, test surfaces, and unresolved questions. Do not research or implement a selected direction.

## Stop conditions

Stop when the problem or decision is too unclear to generate meaningful alternatives; state the missing input.
