# Flux Wayfind

## Input

Decision question, candidate options, criteria, evidence, and consequences.

## Actions

1. State one decision clearly.
2. Map options and decision criteria.
3. Gather only the evidence needed to resolve it.
4. Expose reversibility, risk, and downstream consequences.
5. Resolve, defer with reason, or escalate.

## Contract contribution

- Goal: resolve consequential uncertainty between viable directions.
- System: compare options against explicit criteria and evidence.
- Constraints: do not choose on hidden preference or bypass required authority.
- Evaluation: return rationale, rejected options, consequences, confidence, and risks.

## Output

Return the decision, rationale, evidence, rejected options, consequences, confidence, and remaining risks. Do not turn uncertainty into an implementation task.

## Stop conditions

Stop when the decision cannot be resolved with available evidence or requires user authority.
